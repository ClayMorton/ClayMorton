## Projects

**Clemson accessible LaTeX package** ([GitLab](https://gitlab.com/clemson/external/accessibility/latex))
A LuaLaTeX package and template kit that produces accessible PDFs from LaTeX. The output passes PDF/UA-2 and PDF/A-4f checks and works with screen readers. It fills gaps in LaTeX's tagging, for example the table header associations that screen readers need for complex tables. Clemson's graduate thesis template is built on it.

**Contributing to LaTeX's tagging code** ([latex2e fork](https://github.com/ClayMorton/latex2e), [tagpdf fork](https://github.com/ClayMorton/tagpdf))
Moving the table header work from my package into LaTeX itself, so every tagged LaTeX table gets correct `Headers` arrays.

**Cost-Effective, Scalable Contextual AI** ([repo](https://github.com/ClayMorton/Cost-Effective-Scalable-Contextual-AI))
My senior capstone at WCU: a multi-model retrieval-augmented generation system that answers academic advising questions. Built with PostgreSQL, ChromaDB, Redis, Node.js, React and Docker.

**Cadence** ([App Store](https://apps.apple.com/us/app/cadence-your-day-in-rhythm/id6780302763))
A native iOS app that plans your day from your health readiness and calendar. Built with Swift, SwiftUI, SwiftData, HealthKit, EventKit, Foundation Models and App Intents.
